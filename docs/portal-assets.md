# Portal typography assets

DM Sans is self-hosted for the Harness Law workspace. The normal, variable Latin subset supports font weights **100–1000**. The browser can fall back to the system sans-serif for other scripts.

- CSS source: https://fonts.googleapis.com/css2?family=DM+Sans:wght@100..1000&display=swap
- WOFF2 source: https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2
- Local asset: `public/fonts/dm-sans-latin.woff2`
- License: SIL Open Font License 1.1, retained at `public/fonts/DM-Sans-OFL.txt`
- License source: https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt
- Retrieved: November 22, 2026

The existing Instrument Serif assets are also reused for workspace display headings. Their provenance and license are recorded in `docs/homepage-assets.md`.
